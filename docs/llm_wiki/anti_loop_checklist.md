# Anti-Loop Checklist

Use this before starting any new task.

## Stop And Check

1. Has this source family already been acquired?
2. Has this exact replay already been run?
3. Is the proposed change selector, sizing, exit, capital path, cost model, or source feature set?
4. Can the difference be stated in one sentence?
5. Are missing sources being treated as gaps rather than negatives?
6. Are labels/outcomes excluded from assignment logic?
7. Is this work moving toward paper/shadow trading rather than another research loop?
8. Is the work accidentally putting L0-L5 judgment logic into a skill instead of backend code?

## Default Next Direction

Prefer:

- paper/shadow decision journal
- MDD attribution
- main vs challenger comparison
- mobile read-only dashboard
- policy freeze and promotion discipline
- read-only frontend observation plus MDD attribution journal

Avoid:

- broad source acquisition without a named failure
- replay without a changed frozen input
- selector tweaking followed immediately by replay
- long chat summaries as project truth
- turning skills into strategy engines
- turning the mobile cockpit into a live order engine before acceptance
- rebuilding retired mobile cockpit paths instead of the fixed frontend app SSOT path
